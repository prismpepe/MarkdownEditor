# Markdown エディタ 取扱説明書

Markdown（`.md`）文書を書くためのアプリです。左の編集欄に書くと、右のプレビューにすぐ反映されます。

## 1. はじめに

### 動作環境

- Windows 11
- Microsoft Edge WebView2 ランタイム（Windows 11 には標準で入っています）

### インストール

インストールは不要です。zip を展開してできた `MarkdownEditor.exe` を、好きな場所に置いて起動します。

> 初めて起動したときに「Windows によって PC が保護されました」と表示されることがあります。このアプリには署名がないためです。「詳細情報」→「実行」で起動できます。

## 2. 起動のしかた

| 起動のしかた | 開くもの |
| --- | --- |
| `MarkdownEditor.exe` をダブルクリック | 空の「無題」文書。前回開いたフォルダーがあれば、左の一覧に出ます（前回開いていたファイルは、開きません。起動してすぐに、誤って書き換えるのを防ぐためです） |
| Markdown ファイルを `MarkdownEditor.exe` の上にドラッグ＆ドロップ | そのファイル。同じフォルダーの Markdown が左の一覧に出ます |
| 「3. エクスプローラーから開く」の設定をしたあと、Markdown ファイルをダブルクリック | そのファイル |

## 3. エクスプローラーから開く（ダブルクリックで起動）

一度だけ、次の設定をします。

1. `登録.cmd` をダブルクリックします。登録できたことを知らせるメッセージが出ます。管理者権限は要りません。
2. 任意の Markdown ファイルを右クリックし、「プログラムから開く」→「別のプログラムを選択」を選びます。
3. 一覧から「Markdown エディタで開く」を選び、「常に使う」を押します。

以後、Markdown ファイルをダブルクリックするとこのアプリで開きます。元に戻すときは、`登録解除.cmd` をダブルクリックします。

### フォルダーを右クリックして開く

`登録.cmd` を実行すると、フォルダーを右クリックしたメニューにも、「Markdown エディタで開く」が加わります。

- **フォルダーを右クリック** →「Markdown エディタで開く」で、そのフォルダーの Markdown の一覧が開きます（空の「無題」文書で始まります。前回のファイルは開きません）。
- **フォルダーを開いて、何もない場所を右クリック**しても、同じメニューが出ます（いま開いているフォルダーが対象です）。
- **Windows 11 では、右クリックしてすぐ出る短いメニューには出ません。** 「**その他のオプションを表示**」を押した先の、従来のメニューに出ます。Shift キーを押しながら右クリックすると、はじめから従来のメニューが出ます。
- ドライブそのもの（`F:\` など）を右クリックしたメニューには、出しません。ドライブを開いて、何もない場所を右クリックすると出ますが、ドライブ全体が対象になるため、一覧は上限（10秒、5,000件）までの、途中までの表示になります（「5. 一覧について」を参照）。
- `登録解除.cmd` を実行すると、ファイル用の登録と合わせて、フォルダー用のメニューも消えます。


> `登録.cmd` と `登録解除.cmd` は `MarkdownEditor.exe` と同じフォルダーに置いて使います。exe を別の場所へ移したときは、移したあとにもう一度 `登録.cmd` を実行してください。

## 4. 画面の見かた

画面は、上から順に次の部分でできています。

| 部分 | 場所 | 内容 |
| --- | --- | --- |
| ツールバー | 最上段 | ファイルの操作、印刷・PDF 保存、一覧の切替、表示の切替、プレビューの倍率 |
| 一覧 | 左側 | 現在のフォルダーと、そこにある Markdown ファイル |
| 編集 | 中央 | 編集ボタンの列と、文書を書く編集欄（行番号つき） |
| プレビュー | 右側 | 書いている文書の仕上がり |
| ステータスバー | 最下段 | カーソルの行と列、文字数、改行の種類、文字コード、メッセージ |

ツールバーのボタンは、左から次の順に並んでいます。

| 順 | ボタン | 内容 |
| --- | --- | --- |
| 1 | 📝 新規 | 空の文書を作ります |
| 2 | 📁 フォルダーを開く | 文書のあるフォルダーを選び、左の一覧に出します |
| 3 | 📄 ファイルを開く | ファイルを1つ選んで開きます |
| 4 | 💾 保存 | いまの文書を保存します。保存していない変更があるときだけ青く表示され、保存済みのときは他のボタンと同じ色です |
| 5 | 名前を付けて保存 | 保存先を選んで保存します |
| 6 | 🖨 印刷／PDF | 書いている文書の印刷、または PDF への保存です。使い方は「9. 印刷と PDF 保存」を参照してください |
| 7 | ↻ 更新 | 一覧を取り直し、他のアプリでの文書の変更を確認します |
| 8 | 🔤 フォント | 画面・編集欄・本文・見出し・コード・図のフォント名と大きさを設定します。「表示フォントの設定」を参照してください |
| 9 | 表示（3画面／2画面／編集のみ／プレビューのみ） | 画面に何を出すかを、ここ1か所で切り替えます。「3画面」は一覧・編集・プレビュー、「2画面」は編集・プレビュー（一覧は隠れます）、「編集のみ」「プレビューのみ」はそれぞれを広く表示します |
| 10 | プレビュー倍率（− 数字の欄 ＋ 100% ↔ 全体表示） | プレビューの拡大・縮小です。「8. プレビュー」を参照してください |

- 編集とプレビューの境目（縦の線）をドラッグすると、幅を変えられます。幅や表示の切替は、次回も覚えています。
- 左の一覧が出るのは、「3画面」のときだけです。一覧を隠して編集とプレビューを広く使いたいときは、「2画面」を選びます（Ctrl+\ でも、3画面と2画面を切り替えられます）。
- ウィンドウを狭くすると、ツールバーのボタンは、区切り線で分けたグループごとに、折り返して並びます。
- 一覧の上部の絞り込み欄に、ファイル名（フォルダー名を含む）の一部を入れると、一覧が絞り込まれます。
- 他のアプリでフォルダーを整理したあと、このウィンドウへ戻ると、一覧は自動で最新になります。
- 一覧に出すのは最大 5,000 件、読み込みに使うのは最大 10 秒です。どちらかの上限に達すると、そこまでの一覧を表示し、件数の行に赤字で「（途中までです）」と出ます。ドライブ全体のような大きなフォルダーを開いたときに、長く待たされないためです。もっと下のフォルダーを選ぶと、全部を出せます。途中までの一覧は、ウィンドウを前面に戻しても自動では読み直しません（「↻ 更新」で読み直します）。

ウィンドウのタイトルバーには、アプリの名前とバージョン（例: `Markdown エディタ v1.4.0`）が表示されます。

## 5. 文書を書く

### 基本の操作

- 編集欄に直接書きます。書いた内容は、入力が止まって少しすると、プレビューに反映されます。
- Enter で改行すると、箇条書きや番号付きリストの記号が自動で続きます。記号だけの行でもう一度 Enter を押すと、記号が消えて空行ができ、リストが終わります。
- Tab で2文字分の字下げ、Shift+Tab で戻します。複数行を選んでいれば、選んだ行をまとめて字下げします。
- 編集欄の文字の大きさは、Ctrl+マウスホイールで変えられます。Ctrl+0 で元に戻ります。
- 編集のみの表示にすると、編集欄を広く使えます。プレビューのみの表示では、仕上がりを確認できます。

### 編集ボタン

編集欄の上に、ボタンの列があります。ボタンにマウスを乗せると、名前とショートカットが出ます。

| グループ | ボタン | 内容 |
| --- | --- | --- |
| 編集 | ↶ ↷ ✂ ⧉ 📋 🔍 | 元に戻す、やり直し、切り取り、コピー、貼り付け、検索・置換 |
| 見出し | 「見出し」の選択欄 | 見出し1〜6にします。「本文に戻す」で通常の文章に戻します |
| 文字の装飾 | B　I　S　`</>` | 太字、斜体、取り消し線、コード |
| リスト | • ≡　1.≡　☑　❝ | 箇条書き、番号付きリスト、チェックリスト、引用 |
| 挿入 | 🔗　🖼　▦　`{ }`　― | リンク、画像、表、コードブロック、区切り線 |
| 図 | 「図を挿入…」の選択欄 | Mermaid の図と、Vega-Lite のグラフのひな形を入れます |

- 文字を選んでからボタンを押すと、その文字に書式が付きます。選ばずに押すと、その場所に記号が入り、カーソルが記号の間に置かれます。
- **同じ操作をもう一度すると、元に戻ります。** 太字を2回押す、同じ見出しをもう一度選ぶ、などです。
- 複数行を選んでボタンを押すと、まとめて変換します。空行は飛ばし、字下げは保たれます。箇条書き・番号付き・チェックリストの間は、そのまま変換できます。
- リンクは、`URL` の部分が選ばれた状態で入ります。そのまま貼り付けて書き換えてください。画像も同様に、パスの部分が選ばれます。
- 「図を挿入…」で、次のひな形を入れられます。Mermaid は、フローチャート、シーケンス図、クラス図、ガントチャート、円グラフ、XYチャート（棒グラフ・折れ線）、レーダーチャート、象限図、マインドマップ、状態遷移図、ER図、アーキテクチャ図、Git グラフです。Vega-Lite は、棒グラフ、折れ線グラフ、CSV ファイルから描くグラフです。入れた図やグラフは、そのまま書き換えて使います。
- 「CSV ファイルから」のひな形は、文書と同じフォルダーの `data/sample.csv` を読む書き方になっています。ファイルの場所と、列の名前（`category`、`value`）を、自分のデータに合わせて書き換えてください。

### ショートカットキー

| キー | 動作 |
| --- | --- |
| Ctrl+B / Ctrl+I / Ctrl+E / Ctrl+K | 太字／斜体／コード／リンク |
| Ctrl+Z / Ctrl+Y | 元に戻す／やり直し |
| Ctrl+X / Ctrl+C / Ctrl+V / Ctrl+A | 切り取り／コピー／貼り付け／すべて選択 |
| Ctrl+G | 行番号を指定して移動 |

右クリックでもメニューが出ます。編集欄では、元に戻す、やり直し、切り取り、コピー、貼り付け、すべて選択、検索、置換が選べます。

## 6. 検索と置換

Ctrl+F で検索、Ctrl+H で検索と置換のバーが開きます。編集欄の上の 🔍 ボタンからも開けます。選んでいる文字（1行以内）は、検索する文字列に入ります。

| 部分 | 内容 |
| --- | --- |
| 検索する文字列 | 入力すると、一致する箇所がすべてハイライトされます |
| ▲ 前へ／▼ 次へ | 前後の一致へ移動します（Shift+Enter／Enter、または Shift+F3／F3）。端まで来ると反対側に戻り、「先頭に戻りました」と出ます |
| ✕ | バーを閉じます（Esc でも閉じます） |
| 大文字小文字を区別 | 英字の大文字と小文字を区別します |
| 正規表現 | 検索する文字列を正規表現として扱います |
| 件数 | 「3 / 12 件」のように、現在位置と一致の数を表示します。ない場合は「見つかりません」 |
| 置換後の文字列 | 置換する内容です（空にすると、一致した文字を削除します） |
| 置換 | まず次の一致を選びます。選んだ状態でもう一度押すと、置換して次へ進みます |
| すべて置換 | 一致をすべて置換し、件数を表示します。Ctrl+Z を1回押すと、元に戻ります |

### 正規表現を使うとき

- 「正規表現」にチェックを入れてください。チェックが外れていると、`^` などの記号は普通の文字として探されるため、見つかりません。
- 置換後の文字列では、`$1`（括弧で囲んだ1番目の部分）、`$&`（一致した部分全体）、`$$`（`$` という文字）が使えます。正規表現にチェックがないときは、書いたとおりに置換されます。
- 長さ0の一致（`^` だけ、など）は、一致として扱いません。

| やりたいこと | 検索 | 置換 |
| --- | --- | --- |
| 行頭の「く」を「X」にする | `^く` | `X` |
| 行頭の「く」を削除する | `^く` | （空） |
| 字下げを残して、行頭の「く」を「・」にする | `^(\s*)く` | `$1・` |
| 行頭に「> 」を付ける（空行は除く） | `^(.)` | `> $1` |
| 行末の空白を削除する | `[ \t]+$` | （空） |

> 「すべて置換」の前に、ハイライトされた箇所と件数を確認すると安全です。置換した直後なら、Ctrl+Z で元に戻せます。

## 7. ファイルを開く・保存する

### 開く

- 一覧のファイル名をクリックするか、「ファイルを開く」で選びます。
- 編集中の文書に保存していない変更があるときは、「保存する／保存しない／キャンセル」を聞かれます。
- 「📁 フォルダーを開く」で別のフォルダーを選ぶと、開いていた文書は閉じて、空の「無題」になります。保存していない変更（書きかけの「無題」を含みます）があるときは、先に「保存する／保存しない／キャンセル」を聞かれます。キャンセルすると、フォルダーも文書も、そのままです。同じフォルダーを選び直したときは、文書は開いたままです。

### 保存

- 保存は Ctrl+S です。「無題」の文書を保存すると、保存先を選ぶ画面が出ます。別の名前で保存するときは、Ctrl+Shift+S です。
- タイトルの先頭の赤い「●」と、青く表示された「💾 保存」ボタンは、保存していない変更があることを示します。
- 保存ボタンは、マウスで押した瞬間に保存を始めます（編集中でも1回で反応します）。保存の処理中に重ねて押しても、二重には動きません。
- **自動保存はありません。** こまめに保存してください。

### 文字コードと改行

- 文書を開くとき、文字コード（UTF-8、BOM 付き UTF-8、Shift-JIS、UTF-16）と改行（CRLF、LF、CR）を自動で判別し、**保存するときは同じ形式で書き戻します。** 他のエディターで作った文書を、保存で変えてしまうことはありません。
- 現在の文字コードと改行は、ステータスバーで確認できます。選択欄から変えることもできます（変えると、保存していない変更として扱われます）。
- 新しく作った文書は、UTF-8（BOM なし）、改行は CRLF です。
- 改行が混ざっている文書は、開いたときにお知らせが出ます。保存すると、多いほうの改行にそろいます。
- 文字コードを判別できない文書は、文字を失わないよう、**読み取り専用**で開きます。読み取り専用では、保存と、書き換える操作はできません。
- Shift-JIS で保存しようとして、Shift-JIS で表せない文字（絵文字など）があるときは、保存せずにお知らせが出ます。「UTF-8 に変えて保存」を選ぶと保存できます。

### 他のアプリで書き換えられたとき

ウィンドウを前面に戻したときに、開いている文書が他のアプリで変更されていないかを確認します。

- 保存していない変更がなければ、自動で読み込み直します。
- 保存していない変更があるときは、「変更を捨てて読み込み直す」か「このまま編集を続ける」を聞かれます。続ける場合、保存すると相手の変更は上書きされます。
- 保存の瞬間に変更が見つかったときは、「上書きして保存」か「キャンセル」を聞かれます。
- この確認は、他のアプリが実際にファイルを書き換えたときだけ出ます。自分で開いたファイルを何度保存し直しても、確認は出ず、「保存しました」と表示されるだけです。
- 文書のファイルが移動や削除されたときは、お知らせが出ます。保存すると、同じ場所に作り直します。

### バックアップ

既存のファイルを上書きして保存するとき、上書きする前の内容を `%APPDATA%\MarkdownEditor\backup\` に退避します。**退避は、全体で直近の5回分だけ**残します。6回目からは、保存のたびに、いちばん古いものから自動で削除します（どのファイルのものかは問いません。新しいファイルを初めて保存するときは、退避するものがないため作られません）。

- 退避したファイルの名前は、日時（`20261003_141500_123456.bak` の形）です。
- 元に戻したいときは、退避したファイルをコピーし、拡張子を `.md` に変えて開いてください。
- エクスプローラーのアドレスバーに `%APPDATA%\MarkdownEditor\backup` と入れると、フォルダーを開けます。
- 5回より前に上書きした内容は、取り出せません。大事な文書は、別の場所にもコピーしておいてください。

### 閉じるとき

保存していない変更があると、「保存して閉じる／保存しないで閉じる／キャンセル」を聞かれます。

## 8. プレビュー

右側のプレビューには、書いている文書の仕上がりが表示されます。

- 次のものが表示できます：見出し、段落、箇条書き、番号付きリスト、引用、コード、表、取り消し線、チェックリスト、画像、リンク、埋め込まれた HTML（表など）、Mermaid の図、Vega-Lite のグラフ。
- ` ```mermaid ` で書いたコードブロックは、図として表示されます。図の記述に誤りがあるときは、その図の位置に理由が出て、元の記述も残ります。
  - Architecture Diagram（`architecture-beta`）では、標準のアイコン（`cloud`・`database`・`disk`・`internet`・`server`）に加えて、**`logos:` で始まる名前のアイコン**（例: `logos:slack-icon`、`logos:aws-lambda`、`logos:aws-s3`）が使えます。アイコン集（iconify の `logos`、約2,200個）はアプリに同梱されているため、インターネットに接続しなくても表示されます。
  - `logos` 以外のアイコン集（`mdi:` など）は同梱していません。使うと、そのアイコンは「?」の印で表示されます（図全体は描かれます）。
- ` ```vega-lite ` で書いたコードブロック（中身は JSON）は、グラフとして表示されます。描画にインターネット接続は要りません。JSON や spec に誤りがあるときは、そのグラフの位置に理由が出て、元の記述も残ります。グラフは、ダークモードでも白地で表示されます。
  - データは、spec に直接書く（`data.values`）か、`data.url` で指定します。`data.url` では、次のものが使えます。
    - `https://…` の URL（インターネット接続が必要です。相手のサーバーによっては読めないことがあります）
    - 編集中の文書と同じフォルダー、またはその下のフォルダーにある、`.csv` `.tsv` `.json` のファイル（相対パスで指定します。20MB まで）
  - 文書のフォルダーの外（`../` で上の階層へ出る指定）、絶対パス（`C:\…` など）、`file:` は、安全のため読み込めません。
  - 「無題」の文書は保存先がないため、相対パスのデータは読めません。一度保存してください。
  - データのファイルを別のアプリで書き換えたあと、このアプリへ戻ると、グラフが描き直されます。
- 画像は、文書と同じフォルダーなどにあるものを、相対パスで指定すると表示されます。「無題」の文書は保存先がないため、相対パスの画像は表示できません。一度保存してください。
- 編集欄をスクロールすると、プレビューも同じ場所へ動きます。入力しているときは、書いている場所がプレビューに表示されます。
- リンクをクリックすると、`http` のリンクは普段使っているブラウザーで開きます。他の Markdown ファイルへのリンクは、このアプリで開きます。PDF や Word などのファイルへのリンクは、そのファイルに関連づけられたアプリで開きます。
- ファイルへのリンクは、次の書き方で書けます。

  | 書き方 | 例 |
  | --- | --- |
  | 相対パス（この文書があるフォルダーが基準。`../` で上の階層も指せます） | `[仕様書](docs/spec.pdf)`、`[見積](../shared/見積.xlsx)` |
  | ドライブ名から始まるパス | `[資料](file:///C:/work/資料.pdf)`、`[資料](C:/work/資料.pdf)` |

  - 開けるのは、次の種類のファイルだけです。
    - PDF（`.pdf`）
    - Word（`.doc` `.docx`）、Excel（`.xls` `.xlsx`）、PowerPoint（`.ppt` `.pptx`）
    - リッチテキスト・OpenDocument（`.rtf` `.odt` `.ods` `.odp`）
    - テキスト・表データ（`.txt` `.csv` `.tsv`）
    - 画像（`.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp`）
  - 実行ファイル、スクリプト、ショートカット、マクロ付きの Office ファイル（`.docm` `.xlsm` など）は、安全のため開けません。
  - ネットワーク上の共有（`\\サーバー名\…`）へのリンクは開けません。
  - 「無題」の文書は保存先がないため、相対パスのリンクは開けません。一度保存してください（ドライブ名から始まるパスは開けます）。
  - ファイルが見つからないときや、開けない種類のときは、画面に理由が出ます。
  - パスに日本語や空白が含まれるときは、`[資料](docs/日本語%20資料.pdf)` のように空白を `%20` と書くか、`[資料](<docs/日本語 資料.pdf>)` のように `<` `>` で囲んでください。

### 日本語の強調記号（`**` `*` `~~`）

日本語の文では、強調の記号が、括弧などの記号に接していても強調になります。

```
加入している**「個人賠償責任保険」（火災保険特約）の優先使用を原則**とする。
```

この書き方は、Markdown の標準の規則（CommonMark）では、記号の前後に空白がないと強調にならず、`**` がそのまま表示されます。GitHub など、標準の規則どおりのところでは、前後に半角スペースを入れる必要があります。このアプリでは、**前後が日本語（かな・漢字・ハングル）であれば、スペースがなくても強調になります**。

- 英数字だけの文は、標準の規則のままです（`word**(x)**word` は強調になりません）。
- コードの中（`` `**…**` ``）は、記号がそのまま表示されます。
- このアプリで強調になる書き方でも、GitHub などでは `**` のまま表示されることがあります。ほかの場所へ持っていく文書では、強調の前後に半角スペースを入れておくと、どこでも強調になります。

### プレビューの倍率

| 操作 | 内容 |
| --- | --- |
| − ／ ＋ | 少しずつ縮小／拡大します |
| 数字の欄 | 倍率（10〜500%）を直接入力して Enter |
| 100% | 等倍に戻します |
| ↔ 全体表示 | 横スクロールが要らない大きさに自動で合わせます（Ctrl+9） |
| Ctrl＋マウスホイール（プレビュー上） | 縮小／拡大します |

横長の表などを全体で見渡したいときは、全体表示を使います。ウィンドウの大きさや、2画面の境目を変えても、全体表示のままなら自動で合わせ直します。

### 表示フォントの設定

ツールバーの「🔤 フォント」で、次の6つの部分について、フォント名と大きさを設定できます。変更はすぐ画面に反映され、次回の起動にも引き継がれます。

| 部分 | 内容 | 既定 |
| --- | --- | --- |
| 画面 | ツールバー、一覧、編集ボタン、ステータスバーなど | Yu Gothic UI、14px |
| 編集欄 | 文書を書く編集欄（行番号つき） | Consolas、15px |
| 本文 | プレビューの文章、表、引用など | Yu Gothic UI、14px |
| 見出し | プレビューの見出し。フォント名に加えて、H1〜H4 の大きさを、それぞれ設定できます | 本文と同じ。大きさは本文に対する比率（H1 は 2 倍、H2 は 1.5 倍、H3 は 1.17 倍、H4 は 1 倍） |
| コード | プレビューのコードブロックと、文中のコード | Consolas、13px |
| 図・グラフ | Mermaid の図、Vega-Lite のグラフの文字（軸・凡例・タイトルなど）。Vega-Lite は、既定の大きさに「設定した大きさ ÷ 16」を掛けます | Trebuchet MS 系、16px |

- フォント名は、各部分につき1つだけ設定します。入力欄を押すと、インストール済みのフォントの一覧が出ます。文字を打つと、一覧が絞り込まれます（`メイ` や `Yu` など）。一覧から選ぶか、名前を直接入力します。
- 何も選ばずに入力欄から離れると、いまの設定のままです。
- 空欄は既定の表示です。各行の「既定」ボタンで、その部分のフォント名と大きさ（見出しは H1〜H4 も）を、まとめて既定に戻せます。「すべて既定に戻す」で6つすべてを戻せます。
- 大きさの欄の「▲▼」（または、欄を選んでの ↑↓ キー）は、空欄のときは既定の大きさを基準に、1px ずつ増減します。
- 見出しの大きさは、H1〜H4 の欄に px で入れます（8〜120px）。空欄の見出しは、既定の比率のままです（H5・H6 は設定できません）。
- 大きさは、画面が 8〜40px、編集欄・本文・コード・図が 8〜60px です。範囲を超えると、その範囲の端の値になります。
- 編集欄の大きさは、編集欄での Ctrl＋マウスホイール、Ctrl＋「＋」「−」、Ctrl+0（既定に戻す）でも変わります。どちらで変えても同じ設定です。
- 編集欄は、文字の幅がそろう等幅のフォントを選ぶと、桁がそろって書きやすくなります。
- 「画面」の大きさは、ツールバー・一覧・編集ボタン・ステータスバーを、まとめて拡大・縮小して合わせます。
- 「図・グラフ」を変えると、プレビューの図を描き直します（読んでいる位置は保たれます）。
- Vega-Lite の spec に `config`、`fontSize`、`font` を直接書いているグラフは、その指定が優先され、この設定は効きません。
- 本文の大きさは、「プレビューの倍率」とは別です。倍率は、フォントの大きさに掛かります。
- 印刷・PDF 保存にも、本文・見出し・コード・図のフォントが反映されます（編集欄と画面は印刷されません）。

### 安全のための制限

文書に書かれたスクリプトは、プレビューで動きません。埋め込まれた HTML のうち、`<script>`、`<iframe>`、`<form>` などの危険なもの、`onclick` などの動作の指定、`javascript:` のリンクは取り除いて表示します。HTML の `style="color:red"` のような色や配置の指定は反映されません（`align` や `border` など、HTML の属性は反映されます）。

## 9. 印刷と PDF 保存

ツールバーの「🖨 印刷／PDF」（Ctrl+P）で、プレビューに表示されている内容（保存していない変更も含みます）を、印刷または PDF ファイルにできます。ツールバーや一覧などの画面の部品は出力されず、**本文だけ**が紙面に流れます。文書が空のときは、「印刷する内容がありません」と出て、ダイアログは開きません。

### ダイアログの項目

| 項目 | 内容 |
| --- | --- |
| 出力先 | 「印刷する」または「PDF ファイルに保存する」。選ぶと、実行ボタンの表示が「印刷する」「PDF を保存…」に変わります |
| ページ | 「すべて」または「指定」。指定の書き方は次の節を参照してください。隣に「全 5 ページ」のように全ページ数が出ます |
| 用紙・向き | A4、A3、B5、B4、Letter と、縦／横 |
| 余白 | 標準、狭い、広い、なし |
| 倍率 | 25〜200%（既定は 100%） |
| 幅の広い表は、用紙に収まるよう縮小する | 既定でオンです。用紙の幅に入らない表があるとき、倍率を自動で下げて収めます（下限は 20%）。オフにすると、指定した倍率のままになります |
| 背景色を印刷する | 表の見出しの色や、コードの背景の色を出力します |
| ヘッダーとフッターを付ける | ヘッダーに日付とファイル名、フッターにファイルの場所とページ番号が入ります |
| プリンター | 印刷のときだけ表示されます。使えるプリンターから選びます（既定のプリンターが選ばれています） |
| 部数・白黒で印刷する | 印刷のときだけ表示されます。部数は 1〜99 |
| 仕上がりを確認（PDF を開く） | いまの設定で作った PDF を、Windows で PDF を開くアプリで開き、仕上がりとページ分けを確認できます。確認用の一時ファイルで、保存はされません |

用紙・向き・余白・倍率を変えると、全ページ数を自動で数え直します（「ページ数を調べています…」と出ます）。

### ページの指定

「指定」を選ぶと、ページ番号を入力できます。

| 入力 | 出力されるページ |
| --- | --- |
| `3` | 3ページ目だけ |
| `1-3` | 1〜3ページ |
| `1-3,5` | 1〜3ページと5ページ |
| `5-` | 5ページ目から最後まで |
| `2,4,6-8` | 2、4、6〜8ページ |

- 全角の数字や、全角のハイフン・読点（`１ー３、５`）でも入力できます。
- 書き方が正しくないとき、または全ページ数を超えているときは、入力欄が赤くなり、理由が表示されます。直すまで実行できません。
- 指定したページだけの PDF や印刷になります。**ページ番号は、文書全体での番号のままです**（たとえば2ページ目だけを出力すると、フッターは「2/6」になります）。
- ページの指定は、次に開いたときには引き継がれず、毎回「すべて」から始まります。前回の指定が残って、気づかずに一部だけを出力することを防ぐためです。

### 印刷するとき

1. 「🖨 印刷／PDF」を押します。
2. 出力先を「印刷する」にして、ページ・用紙・プリンターなどを選びます。
3. 「印刷する」を押します。「印刷を依頼しました」と出れば、プリンターへ送られています。

「Microsoft Print to PDF」など、一部のプリンターは、続けて保存先を聞く画面を出します。その画面を取り消すと、「印刷されませんでした」と出ます。

### PDF に保存するとき

1. 「🖨 印刷／PDF」を押します。
2. 出力先を「PDF ファイルに保存する」にして、ページ・用紙などを選びます。
3. 「PDF を保存…」を押して、保存先とファイル名を選びます（既定のファイル名は、文書の名前に `.pdf` を付けたものです）。「保存しました」と出れば完了です。

### 仕上がりについて

- **暗い配色でも、紙面は明るい配色**で出力されます。Mermaid の図も、ダイアログを開いている間だけ、紙向けの明るい配色で描き直されます（閉じると元の配色に戻ります）。
- 表の行、図、画像、引用が、ページの途中で切れないようにしています。ただし、1ページより長いものは切れます。表の見出し行は、ページをまたぐと次のページにも繰り返されます。
- 長いコードは、折り返して出力されます。
- 画面の表示倍率や、画面の幅は、出力に影響しません。

### 制限

- 両面印刷、給紙トレイ、用紙の種類など、プリンター固有の設定は、このアプリからは指定できません。必要なときは、PDF に保存してから、PDF を開くアプリで印刷してください。
- ヘッダーとフッターの内容（日付、ファイル名、ファイルの場所、ページ番号）は固定で、入れ替えられません。付けるか付けないかだけを選べます。
- 保存先のない「無題」の文書では、フッターのファイルの場所は空になります。

## 11. 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 起動しない、画面が真っ白 | Microsoft Edge WebView2 ランタイムが入っているか確認してください（Windows 11 では通常入っています） |
| 検索しても見つからない | `^` や `\s` などの記号を使った式では、「正規表現」にチェックが入っているか確認してください |
| 保存できない | 読み取り専用で開いていないか（タイトルに「（読み取り専用）」と出ます）、保存先のフォルダーに書き込めるかを確認してください |
| 保存したら文字が変わった | 保存のときに文字コードを変える操作（Shift-JIS で表せない文字を UTF-8 に変更した場合など）をしていないか、ステータスバーの文字コードを確認してください。上書き前の内容は、バックアップから取り出せます（直近5回の上書き分だけです） |
| 図が描かれない | 図の記述の誤りは、プレビューの図の位置に理由が表示されます。記述を直してください |
| ファイルへのリンク（PDF など）を押しても開かない | 画面に理由が出ます。ファイルの場所（相対パスは、保存した文書があるフォルダーが基準です）、拡張子（開けるのは「プレビュー」の説明に書いた種類だけです）、ファイル名の空白（`%20` と書くか `<` `>` で囲みます）を確認してください。「無題」の文書は、一度保存してください |
| グラフ（Vega-Lite）が描かれない | グラフの位置に理由が表示されます。JSON の書き方（カンマ、引用符、波括弧）と、spec の項目名を確認してください。書き換えると、自動で描き直されます |
| グラフのデータが読めない（`data.url`） | 相対パスは、保存した文書と同じフォルダーかその下にある `.csv` `.tsv` `.json` だけ読めます。`../` を含むもの、絶対パス、`file:` は読めません。「無題」の文書は、一度保存してください。`https://` の場合は、インターネットへの接続と、相手のサーバーがほかのサイトからの読み込みを許可しているかを確認してください。うまくいかないときは、`data.values` に直接書いてください |
| 構成図（Architecture Diagram）のアイコンが「?」になる | 同梱しているアイコン集は `logos` だけです。`logos:` のあとの名前の綴りが正しいか確認してください（例: `logos:aws-lambda`）。`logos` に無い名前や、`logos` 以外のアイコン集は、「?」で表示されます |
| 画像が出ない | 相対パスが実際の位置と合っているか確認してください。20MB を超える画像は埋め込めません。インターネット上の画像は、接続がないと表示されません。「無題」の文書では相対パスの画像は表示できません |
| 一覧に文書が出ない | 拡張子が `.md` `.markdown` `.mdown` `.mkd` のどれかか、`.` で始まるフォルダーや `node_modules` の中ではないかを確認してください |
| ダブルクリックで開かない | 「3. エクスプローラーから開く」の設定を済ませたか確認してください。手順 3 の「常に使う」の選択が必要です |
| 登録を取り消したい | `登録解除.cmd` を実行してください |
| 印刷で「プリンターを使えません」と出る | プリンターの電源・接続と、ダイアログで選んだプリンターが正しいかを確認してください |
| ページの指定が赤くなる | `1-3,5` のような書き方になっているか、ダイアログに表示されている全ページ数を超えていないかを確認してください |
| 印刷で表が用紙からはみ出す、文字が小さい | 「幅の広い表は、用紙に収まるよう縮小する」にチェックを入れる、用紙を大きくする、向きを横にする、余白を狭くする、のどれかを試してください |
| 突然閉じてしまった | 自動保存と復元の機能はありません。最後に保存した内容までは残っています。上書き前の内容は、バックアップから取り出せます（直近5回の上書き分だけです） |

## 12. 保存される情報

アプリは、次のものを `%APPDATA%\MarkdownEditor\` に保存します。

| 場所 | 内容 |
| --- | --- |
| `settings.json` | 次の「復元される設定」と、印刷・PDF 保存の設定（ページの指定は含まない） |
| `backup\` | 上書き前の退避（全体で直近5回分） |

### 復元される設定

次回の起動で、次の状態に戻ります。

- 前回開いたフォルダー（開いていたファイルは、復元しません。起動してすぐに、前回のファイルを誤って書き換えるのを防ぐためです）。ファイル名を指定して起動した回は、フォルダーも記憶しません。次に何も指定せずに起動すると、その前に使っていたフォルダーが開きます。このときでも、「フォルダーを開く」「ファイルを開く」「名前を付けて保存」で選び直すと、そのあとの使用フォルダーは記憶されます
- ウィンドウの位置と大きさ、最大化の状態（画面の外に出てしまう位置は使わず、既定の位置で開きます）
- 表示の切替（3画面／2画面／編集のみ／プレビューのみ。一覧を出すかどうかも含みます）、編集とプレビューの境目の位置
- プレビューの倍率（「全体表示」かどうかも含みます）
- 表示フォントの設定（編集欄の文字の大きさを含みます）

ウィンドウの位置と大きさは、アプリを実際に閉じたときに保存します。未保存の確認で「キャンセル」した場合は、保存しません。保存していない文書の内容そのものは、復元されません。

このアプリを使わなくなったときは、exe と上記のフォルダーを削除すれば、ほかに残るものはありません（`登録.cmd` を実行した場合は、先に `登録解除.cmd` を実行してください）。
